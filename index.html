01 Academic Project

🔊 Morse Code Audio Decoder

Python + DSP + Adaptive WPM Detection

Developed a real-time Morse code audio decoder using digital signal processing, adaptive timing analysis and language modelling. The system processes recorded and live audio and converts Morse signals into text.

Key Highlights

  • WAV/MP3 and microphone audio input
  • FFT-based carrier-frequency detection
  • Butterworth bandpass filtering and Hilbert-envelope processing
  • Adaptive WPM estimation
  • Real-time Morse detection and decoding
  • Character-level N-gram language modelling
Python NumPy SciPy DSP FFT Audio Processing

02 Academic Project

⚡ Non-Intrusive Load Monitoring

Siemens SENTRON PAC4200 + Machine Learning

Developed a Non-Intrusive Load Monitoring (NILM) system using real-world electrical measurements from a Siemens SENTRON PAC4200 to identify individual appliances from aggregate power-consumption data.

Key Highlights

  • Electrical data acquisition using Siemens SENTRON PAC4200
  • Feature engineering from active/reactive power, current and power factor
  • Random Forest appliance classification
  • Real-world appliance monitoring and verification
  • Data visualization and monitoring pipeline

03 Academic Project

📈 Electricity Load Forecasting

ENTSO-E + Weather Features + LightGBM

Developed a 24-hour German electricity-load forecasting pipeline using historical ENTSO-E load data, weather information, calendar features and machine learning.

Key Highlights

  • ENTSO-E electricity-load data processing
  • Weather and calendar feature integration
  • Lag and time-series feature engineering
  • LightGBM-based load forecasting
  • Backtesting and persistence benchmarking
  • 24-hour recursive forecasting
