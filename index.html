01Collaborative Academic Project

Morse Code Audio Decoder

Python + DSP + Adaptive WPM Detection

A modular Morse code audio decoder developed as a team project for Object-Oriented Programming at TH Köln. The system supports recorded and live audio, carrier-frequency detection, signal processing, adaptive timing and Morse-to-text decoding.

Key Highlights

  • FFT-based carrier-frequency detection
  • Butterworth filtering and Hilbert-envelope extraction
  • Adaptive WPM estimation across multiple transmission speeds
  • Live decoding, visualization and character-level N-gram correction
PythonNumPySciPyDSPOOPAudio Processing

02Technical Reference · Fork

Non-Intrusive Load Monitoring

Siemens PAC4200 + Machine Learning

A technically relevant NILM repository maintained on Shervin's GitHub as a fork. The original implementation demonstrates appliance identification from aggregate electrical measurements using feature engineering and machine-learning methods.
