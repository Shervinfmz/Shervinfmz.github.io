# Shervin Faramarzi Babadi — Portfolio

Professional portfolio website for Shervin Faramarzi Babadi.

## Publish with GitHub Pages

1. Create a public GitHub repository named exactly `Shervinfmz.github.io`.
2. Upload the **contents** of this folder to the root of that repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. The site will be available at `https://shervinfmz.github.io/` after GitHub finishes deploying it.

## Structure

- `index.html` — website content
- `css/style.css` — design and responsive styling
- `js/script.js` — small page interactions
- `assets/cv/` — CV PDF
- `assets/projects/` — project banners
